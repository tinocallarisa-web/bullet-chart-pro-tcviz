Get started

  1. Category and Actual: one bar per item, scaled to fit the visual.
  2. Add Target: the marker, the variance and its % appear by themselves.
  3. Sort by variance % and pick the Report theme or a collection style.
  4. Pro: second target, forecast, bands from measures, small multiples.
