Key Features

⚡

Zero DAX Variance

Actual − Target variance calculated automatically. Absolute value + percentage, color-coded green/red.

🎨

IBCS Mode

One toggle switches to a monochrome IBCS-compliant palette for standards-based reporting.

🔄

Orientation

Horizontal or vertical layout. Switch in a single click from the General format section.

PRO
🪟

Small Multiples / Trellis

Side-by-side panels per dimension value. Independent or synchronized axis scales.

PRO
📏

Reference Lines

Up to 2 configurable vertical benchmarks with custom labels and colors. Propagate across trellis panels.

➖

Negative Values

Automatic bipolar scale with zero-baseline when data contains negative values.

♿

Accessibility

Full keyboard navigation (Arrow / Enter / Escape). High Contrast mode with host color palette.

🔖

Bookmarks & Cross-filter

Selection state persisted via bookmarks. Cross-highlight and multi-visual selection supported.

💬

Tooltips & Drilldown

Canvas report tooltips. Hierarchy drilldown on the category role with drill-navigation controls.

🎯

Conditional Formatting

Per-category actual bar color via the format pane "fx" button — no DAX workaround needed.

🔢

Dynamic Format Strings

Actual, Target and Forecast values respect the measure's native format string. Supports Calculation Groups.

📜

Scroll & Sorting

Vertical scroll when categories overflow the viewport. Native Power BI sort controls wired up.
