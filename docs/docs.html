Bullet Chart Pro — Documentation

A Power BI custom visual that replaces the combination of bar chart + KPI card + gauge with a single, information-dense bullet chart. Actual vs Target comparison, automatic variance calculation, qualitative performance bands — all without writing a single DAX measure.

💡
No DAX required. Drop your Actual and Target measures into the field wells — variance (absolute + percentage) is calculated automatically by the visual.

Quick Start

1

Import the visual

In Power BI Desktop, go to Insert → Visuals → Get more visuals and search for Bullet Chart Pro by TCViz. Click Add. The visual icon appears in your Visualizations pane.

2

Add your data fields

Drag your dimension (e.g. Product Category) to Category, your primary measure to Actual (Real), and your goal measure to Target. A working bullet chart renders immediately.

3

Configure the format pane

Open the Format visual panel (paintbrush icon). Adjust band thresholds, colors, label visibility, and layout width to match your report style. All settings have sensible defaults.

4

[Pro] Enable Trellis

Drag a grouping field (e.g. Region) to Small Multiples By. In the format pane, under Trellis, toggle Enabled on and set the number of columns. Each region renders as a side-by-side panel.

IBCS Mode

IBCS (International Business Communication Standards) defines a monochrome, notation-based standard for business charts. When ibcsMode is true, the visual replaces all custom color settings with a built-in palette:

  • Actual bar — solid black
  • Target marker — outlined rectangle (no fill)
  • Forecast marker — hatched pattern
  • Bands — light to mid gray
  • Positive variance — dark gray
  • Negative variance — outlined (hollow)
💡
IBCS mode is useful for print-ready reports, regulatory submissions, or organizations that mandate notation standards.

Negative Values v1.2

When any value in the Actual or Target measures is negative, the visual automatically switches to a bipolar scale:

  • The X-axis is centered at zero.
  • Bars extend left for negative values and right for positive values.
  • Performance bands are suppressed in bipolar mode (they don't have a meaningful negative interpretation).
  • Variance color logic is preserved — green means above target, red means below, regardless of sign.

Colour per Category v1.2

Format pane → Colors lists every category with its own actualColor picker, so each bar can have a fixed colour of its own — for example, to highlight a key product — without modifying the visual's built-in variance colors. Rule-based (fx) conditional formatting is not available yet.

⚠️
Colors picked from the "Recent colors" panel that result in an empty hex string are silently ignored — the bar falls back to the default actualColor. This is by design to prevent invisible bars.

Dynamic Format Strings v1.2

The visual reads the format string directly from the measure's metadata. This means:

  • If your measure is formatted as €#,##0.0, values appear with the euro symbol and one decimal automatically.
  • Calculation Groups that swap format strings at runtime are fully supported — the visual re-reads the format on every update cycle.
  • The same logic applies to Actual, Target, and Forecast independently — they can each carry a different format string.

Trellis — Advanced Notes

Scale synchronization

With syncScale: true (default), the visual computes the maximum value across all panels and uses that as the shared domain. This makes absolute comparisons between panels meaningful. Set syncScale: false when you want to compare the shape/distribution of values rather than magnitudes (e.g., ranking within each region).

Category colours in trellis

Per-category colours propagate to all panels via a canonical row index mapped from the category field. Each category always receives the same color regardless of which panel it appears in.

Legend with trellis

The legend height is automatically subtracted from the available trellis layout space, so it never overlaps panel content at any visual size.

Bookmarks & Cross-filtering v1.2

The visual declares supportsBookmarkActions: true. Selection state (which categories/bars are highlighted) is serialized and restored when a Power BI bookmark is applied. This enables storytelling flows where each bookmark shows a different subset of highlighted data.

Cross-visual filtering (supportsSynchronizingFilterState) and multi-visual selection (supportsMultiVisualSelection) are also active — clicking a bar filters other visuals on the page just as standard Power BI visuals do.

FAQ

Do I need to write a DAX measure for variance?

No. When both Actual and Target fields are populated, the visual calculates variance (absolute and percentage) automatically. No DAX is required.

What's the difference between Free and Pro?

The Free tier includes the full bullet chart with variance, bands, IBCS mode, reference lines, a colour per category, bookmarks, and accessibility. The Pro tier adds three features: Small Multiples / Trellis (side-by-side panels), the Forecast marker, and vertical orientation.

My bands don't align with the bars. What's wrong?

Bands are relative to the data maximum, not a fixed scale. If your scale looks padded or different from what you expect, check whether a slicer or filter is reducing the data range. As of v1.2.0.0, bands use the data max directly — if you upgraded from an older version you may need to re-enter your band1Pct / band2Pct values.

Can I use this with Calculation Groups?

Yes. Dynamic Format Strings (v1.2+) are read from the measure's metadata on every render, so Calculation Groups that swap format strings at runtime work correctly for Actual, Target, and Forecast independently.

How do I get trellis panels to share the same scale?

In the format pane, under Trellis, ensure Sync Scale is toggled on (it's on by default). The visual computes the global maximum across all panels and uses it as the shared domain.

My actual bar color shows as white after picking from Recent Colors.

The "Recent colors" picker can sometimes return an empty string instead of a hex value. The visual detects this and falls back to the default actualColor to prevent invisible bars. Pick the color directly from the color wheel or hex input instead.

Does the visual work in Power BI Embedded / Publish to web?

Yes, for the Free tier. Pro features require a valid Power BI Pro or Premium Per User license for the end user, as enforced by IVisualLicenseManager. Publish to Web (anonymous) does not support license enforcement — Pro features are not available in that mode.

The visual shows a landing page with no data. Why?

The Category and Actual fields are both required. If either is empty the visual renders a landing page placeholder. Check your field wells and ensure at least one measure and one dimension are connected.

How do I report a bug or request a feature?

Open an issue on GitHub or email support@tcviz.com. Please include the visual version, a screenshot, and the steps to reproduce.
