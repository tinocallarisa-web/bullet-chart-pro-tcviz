WHY THIS SUBMISSION
Replaces 1.4.0.0: getFormattingModel (same objects/properties), on-object formatting, 12
languages, setup guide, style templates, 2 new Pro features, fixes. API 5.11.1.

PRO PREVIEW
Without a licence, IN EDIT MODE ONLY, Pro features render under a "Pro preview" watermark.
Intentional. In reading view, before the licence resolves and where licences cannot be read
(Publish to Web, embed, export) the FREE result is drawn, no watermark.

TESTING - FREE (no plan)
1. Category + Actual + Target: bars, target, variance, bands. Edit mode: setup guide on top;
close with X.
2. Click a bar: cross-filter, others dimmed. Ctrl+click, right-click menu, arrows/Enter/Esc.
Bookmark restores it. allowInteractions false: no selection.
3. Format > Style template: pick Contrast; the colours change.
4. Edit mode, add Second target, a measure in Band 1 limit, Forecast, Small Multiples By or
Vertical: watermark + Power BI banner, then Upgrade bar. Reading view: free chart.

TESTING - PRO (plan "bullet-chart-pro-tcviz")
1. Second target: hollow marker, legend, tooltip with its variance.
2. Band 1 limit / Band 2 limit / Band maximum: per-row bands.
3. Small multiples, Forecast, Vertical: no watermark, no notice.

PERSISTPROPERTIES
Only on a click in the guide (step, Try, template, Finish/X) and once when the template is
changed in the format pane (clears the settings it defines). Never in the selection callback.

PRIVACY
No network, telemetry, cookies or storage. privileges: []. No innerHTML. Start-screen links
open only on click via host.launchUrl. npm audit 0; ESLint clean.

LICENSING
IVisualLicenseManager only. Pro if Service ID ends in ".bullet-chart-pro-tcviz", state
Active or Warning. Never blocks render; failure = Free, no prompts. No own licensing UI.

RENDERING EVENTS 1:1
One renderingStarted and one Finished/Failed per update(). Repaints outside update()
(licence, selection, guide) raise none.
