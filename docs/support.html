Quick start

  1. Add the visual from Microsoft AppSource.
  2. Drag a dimension field (e.g. Region, Month) into the Category well.
  3. Drag your real/actual measure into the Actual (Real) well.
  4. Drag your target measure into the Target well.
  5. Variance (absolute + %) is computed automatically — no DAX needed.

Common questions

Why is variance not showing?
Make sure both the Actual and Target fields are populated. Variance is only calculated when both values are present. Also check that "Show variance label" is enabled in the Format pane → Variance section.

Can I change the green/red threshold?
Yes. In the Format pane → Variance section, set the "Threshold for green/red" value. Variances above this number are shown in green; below are red (default: 0).

How do I unlock Pro features?
Purchase a Pro license through Microsoft AppSource. After purchase, Pro features (trellis, forecast marker, vertical orientation) activate automatically for licensed users.

The visual shows "Unlicensed Features" for some users
Each user who views reports containing Pro features needs their own Pro license. Go to Microsoft 365 admin center → Billing → Licenses to assign licenses.

Does this work in Power BI Embedded or Report Server?
Free features work in all environments. Pro license validation via IVisualLicenseManager requires Power BI Service.
