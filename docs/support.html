Quick start

  1. Add the visual from Microsoft AppSource.
  2. Drag a dimension field (e.g. Region, Month) into the Category well.
  3. Drag your actual measure into the Actual (Real) well.
  4. Drag your target measure into the Target well.
  5. Variance (absolute + %) is computed automatically — no DAX needed.

Frequently asked questions

Data & Variance

Why is variance not showing?

Make sure both the Actual and Target fields are populated. Variance is only calculated when both values are present. Also check that Show variance label is enabled in Format pane → Variance.

Can I change the green/red threshold?

Yes. Format pane → Variance → Green/red threshold. Variances above this number are shown in green; below in red. Default is 0.

Does it support negative values?

Yes. When your data contains negative values the chart automatically switches to a bipolar scale with a zero baseline drawn at the correct position.

Can I format numbers as currency, thousands, etc.?

Yes — the visual reads the format string directly from your Power BI measure. Apply the format in Power BI (e.g. €#,0) and the visual will use it automatically. Calculation Groups are also supported.

Features & Format pane

How do I use Small Multiples (trellis)? Pro

Drag a dimension into the Small Multiples By field. In Format pane → Small Multiples, set the number of columns and choose whether to sync the scale across panels.

How do I add reference lines?

Format pane → Reference Lines → enable Line 1 or Line 2. Set the value, label and color. Reference lines appear across all panels in Small Multiples mode.

Can I color individual bars differently?

Yes. Format pane → Colors → click the fx button next to any category name to set a custom color or a conditional formatting rule for that bar.

How do I enable drilldown?

Add a hierarchy or multiple fields to the Category well. Use Power BI's drill navigation buttons (top-left of the visual) or double-click a bar to drill down.

Does it support High Contrast mode?

Yes. The visual detects Power BI's High Contrast setting automatically and adjusts all colors (bars, axis, legend, bands) to use the system palette.

Can I use keyboard navigation?

Yes — ← → ↑ ↓ cycle through bars, Enter selects, Escape clears selection. The focused bar is highlighted with a visible focus ring.

Licensing

How do I unlock Pro features?

Purchase a Pro license through Microsoft AppSource. After purchase, Pro features (Small Multiples, Forecast marker) activate automatically for licensed users in Power BI Service.

Some users see "Unlicensed Features"

Each user who views reports containing Pro features needs their own Pro license. Go to Microsoft 365 admin center → Billing → Licenses to assign licenses to your team.

Does this work in Power BI Embedded or Report Server?

Free features work in all environments. Pro license validation via IVisualLicenseManager requires Power BI Service. In Embedded or Report Server, the visual renders free-tier features only.
